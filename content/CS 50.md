Problem: the n variable will remain undefined because its  scope is soley within the {} in which it was declared.

> **Rule**: Declare a variable at the beginning of the `main` function (outside of any loops or conditionals) to give it a wider scope.  You need to do this if you want to access the variable outside the block where it would otherwise be declared.

# Tips when coding
- create a function with no output (so start with void)
- for example you want to print a row of "n" number of bricks

```
#include <stdio.h>

void print_row(int n);

int main(void)
{
    for (int i = 0; i < 3; i++)
    {
   print_row(3);
    }
}

void print_row(int n)
{
    for (int i = 0; i < n; i++)
    {
        printf("#");
    }
    printf("\n");
}

```

Example above of bad coding; you are repeating the same number multiple times; better to make it into a variable to reduce chance of errors (in case you wanna change the number you have to keep changing the corresponding number) as below:

```
#include <stdio.h>

void print_row(int n);

int main(void)
{
    int n = 3;
    for (int i = 0; i < n; i++)
    {
   print_row(n);
    }
}

void print_row(int n)
{
    for (int i = 0; i < n; i++)
    {
        printf("#");
    }
    printf("\n");
}

```
