# Binary

Base 10 vs other bases
Base 2 - Binary base system used by computers.  Binary digit = bit; a bit is the smallest unit of data, representing a binary value, either 0 or 1.
bits = transistor = lightbulb  (3 lightbulbs = 3 bits)
byte = 8 bits; 
2^n - 1 = max value; n = # of bits
so for 1 byte, max value is 255
for 3 bits, max value is 7

# ASCII

- allocated originally 7 bits, then became 8 bits, so a total of 255 + 0 = 256 characters can be represented.
- example:
	- 01001000      01001001     00100001
		- 72               - 73            -33
		- hi!

- example: 1 byte / 8 bits
- Binary place values, where 
128, 6, 32, 16, 8, 4, 2,

# RGB 
- normally RGB uses 8 bits per color
- so standard 24-bit color because each pixel contains 3 channels, each with 8 bits.  8 x 3 = 24 
- in 32-bit color there's an extra 8 bits for alpha (transparency)
- 1 pixel is represented by at least 3 bytes.
